# 作品 - 名著影像解读网页

## 核心结论
-「把名著转成可交互的影像网页」的一次完整实践：AI 生成画面 → 视频压缩 → 前端展示 → 视觉动效，四个环节自己跑通。
- 作品用 8 幕分镜讲《傲慢与偏见》，配粉绿低饱和复古油画风与玫瑰、珍珠装饰，用入场帷幕动画引导观看，属于「交互叙事型网页」。

## 可复用方法
1. **从母带重编码**，不在已压缩文件上二次压缩，避免画质累积损失。
2. **降分辨率提像素码率**：页面实际显示约 980px，用 1280x720 在 700k 码率下比 1080p 更锐利。
3. **轻度降噪**：AI 生成片颗粒最吃码率，`hqdn3d=0.6:0.6:3:3` 去掉颗粒后细节反而留得住。
4. **两遍 ABR** 适合「必须 ≤ N MB」的需求：CRF 单遍不易精确控体积。
5. 装饰层 z-index 低于内容层，避免遮挡文字与视频——网页侧的可用性经验。
