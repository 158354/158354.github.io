# 作品 - 青春校园模拟器

## 核心结论
- 这是一款**四年制大学生活模拟养成游戏**，用「学期 × 周」的时间轴驱动，把选课学习、社团活动、社交恋爱、假期打工串成一条可反复重玩的成长线。
- 它的技术关键点是**单文件 HTML 实现复杂状态机**：全部逻辑、样式、数据内联在一个约 858KB 的文件里，双击即可运行，靠浏览器本地存储实现存档与导出，无需后端和数据库。
- 设计上把「选择」做成核心交互——每次选社团、送礼物、约会地点都是分支，配合随机事件与结局图鉴，形成「多周目收集」的动机。

## 可复用方法
1. **用时间轴做叙事骨架**：以「第 N 学期 · 第 N 周 / 期中期末」推进，天然适配养成节奏，也方便挂载事件。
2. **属性 + 好感度双系统**：多维属性（智力/社交/艺术/体质/外貌/才艺等，部分上限 100）决定成长上限；NPC 好感度（出现 150 次）驱动恋爱与社交分支。
3. **随机事件要兜底**：源码里有 `[Event Error] 某周事件执行失败，已跳过` 的容错——随机事件系统必须为异常留后路，否则一个坏事件会卡死整局。
4. **存档可导出/导入**：既用本地存储做便利存档，又提供导出文本，避免换设备丢进度。
5. **移动端与老内核兼容**：`user-scalable=no` + 固定开始界面布局 + 用 `top/right/bottom/left` 替代 `inset`，这些细节决定作品能不能在别人手机上跑起来。
6. **角色创建先于玩法**：姓名/性别/性格（影响剧情与对话）/外貌定制，再用「掷骰子随机 + 不满意重掷」降低上手门槛。
